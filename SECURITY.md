# Сообщения об уязвимостях

Не публикуйте ключи, пароли, переписку и данные клиентов в issues или pull requests.

Для сообщения об уязвимости используйте раздел GitHub **Security → Advisories → Report a vulnerability**, если он доступен. Если приватная форма не включена, создайте issue только с просьбой предоставить приватный канал связи, без подробностей эксплуатации и чувствительных данных.

Укажите commit, условия воспроизведения и возможное влияние. Используйте синтетические данные. Проверяйте только системы, владельцы которых разрешили такую проверку.

Перед запуском настройте собственные секреты, HTTPS, доступы и резервное копирование по эксплуатационной документации.
