# Администрирование CRM и каналов

26.10.2026 владелец уточнил целевой сценарий: лёгкая интеграция с amoCRM, добавление
каналов, загрузка сотрудников/ролей из CRM, управление доступом и выбор воронки/этапа
для создаваемых обращений. Образец — экраны интеграции и каналов Wazzup, указанные
в рабочем чате. Приватные ссылки и реальные идентификаторы в репозиторий не переносим.

Существующие решения сохраняются: по умолчанию «Неразобранное», без автоматического
назначения; явный выбранный рабочий этап применяется к новым сделкам; оригиналы
вложений в нашем приватном хранилище. Живые тесты и переключение пока отложены.

Сотрудники и названия CRM-ролей загружаются через Users/Role API amoCRM с правами
администратора. Импорт атомарный: ошибка или неполный ответ не стирает прежний реестр.
Отсутствующие в полном новом списке сотрудники становятся неактивными. Идентичности
связываются только по CRM ID; совпадения имени/почты не объединяют людей. Локальные
пароли и административные права импортом не создаются.

Администратор компании выбирает канал и права людей: менеджер — свои клиенты по
текущему ответственному сделки CRM; руководитель — ответы всем клиентам канала; контроль
качества — без отправки; без доступа — запрет. Видимость в штатном чате остаётся по
правам amoCRM. Панель показывает CRM-роль как исходные
данные, отдельно от назначаемой роли канала. Автоматического распределения клиентов нет.
Применение ролей включает явную политику этого канала. Нативный ответ связывается с
пользователем через amojo ID; неизвестная/неактивная личность не получает доступ.
Отправка повторно проверяет право перед HTTP-вызовом, поэтому отзыв действует и для
уже принятого задания. Менеджеру текущий ответственный читается автоматически через
read-only API сделки, в том числе после принятия «Неразобранного». Контактный ответственный
интеграции не считается ответственным новой сделки. При неизвестном ответственном отправка
не разрешается; при временном отказе чтения событие остаётся для безопасного повтора.

Проверки: синтетические API ответы пользователей/ролей, пагинация и ошибки; атомарность
импорта, изоляция компании, сохранение прежнего реестра при сбое; роли на native-ответах
и отзыв после постановки в очередь; UI выбора людей/канала/ролей. Реальные настройки
Wazzup этим не обследованы: кабинет из доступного браузера не загрузился (таймаут).

Источники: [Users API amoCRM](https://www.amocrm.ru/developers/content/crm_platform/users-api),
[настройки интеграции Wazzup](https://wazzup24.ru/help/amocrm/zatem-nastrojte-integraciju/).
